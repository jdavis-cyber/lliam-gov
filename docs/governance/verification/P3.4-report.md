## Expected-deny cases (by design)
- A `.pth` file, a base64-decode-into-executor combo, an install-hook file, or
  an obfuscated-subprocess command anywhere in the tree → gate exits non-zero
  (build blocked).
- Any OSV finding at/above the `--fail-on` severity (default `high`) → gate
  exits non-zero.

## CI wiring note
The three gates are **locally runnable** (the whole Phase 3 verification ran
gates locally — no CI credits this cycle). The governance-gates workflow jobs
that invoke them (GATE 9 supply-chain-artifact, GATE 10 sbom-ai-bom) are ready
to add to `.github/workflows/governance-gates.yml`; the repo's workflow-edit
safety hook held that change for the review pass. Ready-to-add snippet:

```yaml
  supply-chain-artifact:
    name: Supply-chain artifact gate
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v7
      - uses: actions/setup-python@v6
        with: { python-version: "3.13" }
      - run: python "${GOV_CI_DIR}/supply_chain_gate.py"
  sbom-ai-bom:
    name: SBOM + AI-BOM
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v7
      - uses: actions/setup-python@v6
        with: { python-version: "3.13" }
      - run: python -m pip install --quiet pyyaml
      - run: python "${GOV_CI_DIR}/generate_bom.py" evidence/bom
      - uses: actions/upload-artifact@v4
        with: { name: sbom-ai-bom, path: evidence/bom/ }
```
