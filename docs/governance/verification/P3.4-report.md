## What was tested
1. **LG-SS-04:** `supply_chain_gate.scan_tree` flags `.pth` files (including
   release/build outputs), multiline base64-decode-into-executor calls, root
   setup hooks, and obfuscated subprocess calls; missing roots fail closed.
   It also flags an install-hook file
   (`sitecustomize.py`); a clean tree yields no findings; `run_gate` returns a
   non-zero exit code on a hit and zero on a clean tree.
2. **LG-SS-02:** `osv_gate.evaluate` parses CVSS v3 vectors, blocks critical
   vectors at the critical threshold, preserves low vectors below high, and
   fails closed on invalid thresholds/unrated or malformed results.
3. **LG-SS-05 / IN-02 / IN-03:** `generate_bom.build_sbom` inventories the
   pinned `uv.lock` dependency set (not the CI runner environment);
   `build_ai_bom` indexes the approved
   providers (lmstudio, ollama, vllm, bedrock), the carded models, and the
   approved MCP servers and vetted skills/provenance reconciled from the P3
   policy/manifest artifacts. Missing source inputs fail closed.
4. **Real-repo run:** `supply_chain_gate.py` on the repo → **OK, no unsafe
   shapes**; `generate_bom.py` → lockfile SBOM + AI-BOM produced.

## Expected-deny cases (by design)
- A `.pth` file, a base64-decode-into-executor combo, an install-hook file, or
  an obfuscated-subprocess command anywhere in the tree → gate exits non-zero
  (build blocked).
- Any OSV finding at/above the `--fail-on` severity (default `high`) → gate
  exits non-zero.
