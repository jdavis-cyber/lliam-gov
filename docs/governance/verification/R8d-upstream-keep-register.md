## D4 rule applied

This repo is a governance fork of **Hermes Agent (Nous Research, MIT)**. For every
`hermes` string R.8d asked: *is this Lliam-GOV naming itself (→ rename), or is it
upstream Hermes's own identity / attribution / a live inherited contract (→ KEEP)?*
When genuinely ambiguous, the string was **kept and listed here** — over-crediting
upstream is safe; erasing attribution is the failure mode.

R.8d touched **prose only** (`.md`/`.mdx`/`.yaml` + Docusaurus config/labels).
All code (`.py`/`.ts`/`.js`/`.sh`/`.tmpl`) and generated/installer-coupled
artifacts are left to **R.8e-3**.

   quickstart / installation. The root `README.md` already points the fork's own
   installs at `raw.githubusercontent.com/jdavis-cyber/lliam-gov/...`. The website
   still points at the upstream host. Kept (working upstream link) pending a
   decision on whether the fork self-hosts a download site.

   and `editUrl: github.com/NousResearch/hermes-agent/edit/...`. These drive
   `yarn deploy` (gh-pages) and the per-page "edit" link. Kept as upstream; a
   fork that publishes its own docs site would repoint them to
   `jdavis-cyber/lliam-gov`.
3. **`website/docs/index.mdx`**: "Nous Research, the lab behind **Lliam-GOV**,
   Nomos, and Psyche". Here the list enumerates Nous's *own* products, so the
   original "Hermes" arguably refers to upstream. Renamed to Lliam-GOV (it is the
   fork's own product page); flagged in case Jerome prefers to restore "Hermes"
   as the Nous product in that specific lineage sentence.
