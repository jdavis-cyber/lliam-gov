## What was tested
1. **LG-DP-01/02:** a doc with a `CUI` banner + SSN/DOB → classified `cui` with
   the marking captured; PII without a banner still → `cui`; a public doc →
   `public`; low-side → everything `public` (no-op).
2. **LG-DP-04:** the pattern pack matches SSN and DOB; clean text → no hits.
3. **LG-DP-10 (key VERIFY):** exposing CUI taints the session; a tainted
   session is **blocked from a non-allowlisted sink** (`pastebin.test`) but
   **allowed to an allowlisted sink** (`agency.mil`); an untainted session is
   never blocked. Runtime binding: after CUI exposure the PDP escalates
   `network.egress`/`external_send` to `hitl_approve` (origin `cui_taint`)
   while reads stay allowed.
4. **LG-DP-07/08:** encrypt→decrypt round-trips; ciphertext does not contain
   the plaintext; the key store path resolves under `<lliam_home>/keys` and is
   confirmed on the `file_safety.is_write_denied` denylist (the agent cannot
   rewrite the key that protects CUI).
5. **LG-DP-11:** `mask_tool_result` redacts PII from a result; the retention
   TTL is read from `security.data_protection.result_retention_ttl_seconds`.
6. **Secret redaction to provider prompt + ledger (DP-03):** re-attested green
   via the P1 secret-scope isolation suite + ledger redaction-on-write.

## Expected-deny / expected-gate cases (by design)
- CUI-tainted session → egress to a non-allowlisted sink: **blocked**
  (`dlp_egress_decision`) / escalated to HITL (PDP).
- Agent write tool targeting `<lliam_home>/keys/**`: **denied** (LG-DP-08).
- Untainted session, or egress to an allowlisted sink: **not** blocked
  (capability preserved).
