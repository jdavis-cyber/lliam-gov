## What was tested
1. **LG-SC-07 (key VERIFY):** an allowlisted least-privilege stdio server
   (`gov-filesystem`) → **allowed**; an unlisted server → **rejected**
   (deny-by-default).
2. **LG-SC-05:** a server declaring a write tool outside its approved scope →
   **rejected** ("write tool outside scope"); an approved write tool within
   scope (`gov-ticketing` → `create_ticket`) → allowed; a server with no
   `tools.include[]` → rejected (explicit include required).
3. **LG-SC-04:** `curl … | sh`, `>> ~/.bashrc`, `crontab -e` command shapes →
   **blocked** (IOC/shell-egress/persistence) regardless of allowlist status.
4. **LG-SC-08:** an HTTP MCP transport without TLS → **rejected**.
5. **LG-SC-03:** a third-party skill with no clean provenance → **refused**;
   a vetted builtin with clean provenance → allowed.
6. **Capability preservation:** low-side / enforce off → all servers and skills
   allowed (complete no-op; shipped MCP loading unchanged).

## Expected-deny cases (by design)
- Any live `mcp_servers.<name>` not in `approved_servers[]` (deny-by-default).
- A server whose command/args match a shell-egress / OS-persistence IOC shape.
- A write tool outside the approved server's `write_tools` scope, or a server
  with no explicit `tools.include[]`.
- An HTTP/StreamableHTTP MCP transport that does not require TLS.
- A third-party skill without clean provenance (under `require_signed_skills`).
