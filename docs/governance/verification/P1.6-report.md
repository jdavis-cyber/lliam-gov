## SoD design — honest gate (hard rules + tracked deviations)
The gate separates **non-waivable** rules from **waivable** ones:
- **Non-waivable (hard):** Approver ≠ Engineer (the acting engineer is the NPE agent `npe:lliam-gov`, the approver is the human — separated by construction) and Auditor independence (auditor `auditor@independent.mil`, not any reviewed party). These can never be satisfied by a deviation.
- **Waivable:** CAIO ≠ AI Risk Owner (owns-vs-accepts risk) and Approver ≠ ISSO (ISSO owns control implementation). In the single-operator eval the operator co-holds both pairs.

**The single-operator concentrations are NOT a silent green** — the review correctly flagged that an earlier cut over-claimed SoD. The gate now *detects* both concentrations and reports them as **ACCEPTED DEVIATIONS**, each recorded in `roles.yaml` → `sod_deviations` with a justification, accountable owner (`jdavis@agency.mil`), and review-by date. Result: **0 blocking conflicts, 2 tracked deviations** — an honest posture an auditor can interrogate, not a tautological pass.
