## Design — why a startup gate, not hot-path edits
The live resolvers (`runtime_provider.resolve_runtime_provider` etc.) have many
return points and a large test surface. Rather than risk that hot path, the
enforcement seam mirrors the P1.5 control-plane-auth gate: a single fail-closed
`enforce_provider_allowlist_at_startup` reads the CONFIGURED provider on every
routing path and refuses to start a CUI profile that names a non-allowlisted
provider/host. The `validate_provider` function is also the runtime authority
the resolvers/builders call — proven directly across all 5 paths.

## What was tested
1. **LG-MP-02 (the key VERIFY):** an approved in-boundary provider (`lmstudio`
   local, `bedrock` GovCloud) → **allow on all 5 paths** (parametrized); a
   non-allowlisted provider (`openrouter`) → **deny on all 5 paths**.
2. **LG-MP-02 host bypass:** the `bedrock` slug with the COMMERCIAL
   `us-east-1` host (not GovCloud) → **deny** ("host not approved") on every
   path — closes the right-slug/wrong-endpoint bypass.
3. **LG-MP-03:** a CUI route over a plaintext `http://` GovCloud base_url →
   **deny** (TLS required).
4. **LG-MP-04:** high-sensitivity CUI to an approved *cloud* provider →
   `approve` (HITL clamp); to a *local* provider → `allow`.
5. **Fail-closed:** blank provider → deny; validator parse error → deny.
6. **Startup gate:** allowlisted primary passes; a non-allowlisted
   primary / fallback / MoA reference slot / delegation each **raises
   `ProviderAllowlistError`**; advisory (no raise) when the enforce flag is off
   or posture is low-side.
7. **Capability preservation:** low-side posture / `enforce: false` → the
   validator and gate are complete no-ops (shipped multi-provider routing
   untouched).

## Expected-deny cases (by design)
- Any provider not on `providers[]` (deny-by-default, fail-closed).
- Right slug + wrong (non-GovCloud/commercial) host.
- CUI over a plaintext base_url, or to a non-US/non-local residency, or a
  provider lacking no_train terms.
- Blank provider on any path.
- High-sensitivity CUI to an approved *cloud* provider → HITL (`approve`),
  not auto-allow.
