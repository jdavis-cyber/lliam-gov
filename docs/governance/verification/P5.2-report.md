## Design — recurring, not pre-merge; capability-preserving
`scheduled_assurance_cron.sh` is the post-deployment RECURRING control-evidence
stream (LG-GV-07 cATO input), fail-closed on unset `HERMES_HOME`/`HERMES_CONFIG`
(an unpinned home would verify the wrong install and report a false OK) — the
same discipline as the existing `audit_chain_cron.sh`. `control_effectiveness`
is distinct from `go_no_go_gate`: the latter is a release precondition, this is
the recurring detective control feeding re-authorization. Output monitoring is
graduated: bias/toxicity is **detect-and-log** (generated content is flagged
for metrics + the LG-HO-09 appeal channel, never censored); PII/CUI blocks
**only for an egress sink** — the same content to an internal workspace sink is
allowed so the agent can still work with CUI it legitimately processes,
composing with the existing DLP taint gate (LG-DP-10) and LG-PI-09.
