## Design — durable, dual-seam, fail-closed, no false suspension
The kill-switch state is a **durable file** under the agent home (outside the
write-safe-root): a halt survives thread/process boundaries and cannot be
cleared by an ordinary agent write. A corrupt/unreadable state file is treated
**fail-closed** (assumed engaged) so a tamper cannot silently re-enable
autonomy. Engaging halts **both** seams — the tool chokepoint returns a halt
`ToolGuardrailDecision` and every inference routing path
(primary/fallback/MoA/auxiliary/delegation, all through
`resolve_runtime_provider`) raises `KillSwitchEngaged`. Recovery is
**fail-closed on a broken chain**: `recover_and_reenable(verify_ok=False)`
keeps the halt; `verify_ok=True` clears the halt **and** containment entirely.
Absent a state file the switch is NOT engaged and every guard is a complete
no-op — **no false auto-suspension on steady state** (the FINAL-gate
requirement).

## What was tested (the AI-501 VERIFY criteria)
1. **Kill-switch → tool exec + inference halt (LG-IR-01):** after `engage`,
   `guard_tool_dispatch` returns an `action="halt"` decision and
   `assert_inference_live` raises `KillSwitchEngaged`; the halt is durable
   across threads.
2. **Recover to the last signed-tag baseline + verify_chain PASS before
   re-enable (LG-IR-08):** `recover_and_reenable(verify_ok=False)` returns
   False and KEEPS the halt (chain broken → fail-closed);
   `verify_ok=True` returns True, clears the halt, and **restores full
   capability** (tool dispatch + inference flow again, containment cleared).
3. **Containment (LG-IR-02):** `engage(contain_classes=[...])` contains named
   classes while leaving others uncontained.
4. **No false auto-suspension:** not engaged by default; a repeated
   engage→recover drill returns cleanly to steady state each cycle.
5. **Forensics (LG-IR-04/07):** engage records reason + actor to the durable
   state and emits `killswitch.activate` to the ledger.
6. **Live wiring:** both `governance_audit_hooks.py` and `runtime_provider.py`
   call the guards; the IR runbook is present with kill-switch / 72-hr /
   DIBNet / severity / chain-of-custody content.

## Expected-deny cases (by design)
- When engaged: ALL tool execution is halted and ALL inference raises — this is
  the intended emergency posture, not a capability regression (it clears
  entirely on recovery).
- Recovery is refused (halt retained) when the audit chain does not verify
  (LG-IR-08 fail-closed).
- A corrupt kill-switch state file is treated as engaged (fail-closed).
