## What was tested
1. **LG-NE-01/03 allowlist:** `api.github.com` (web) allowed; `*.nist.gov`
   parent-domain wildcard allowed for `csrc.nist.gov`; `pastebin.test` denied
   by default; a surface mismatch (`api.github.com` on `browser`, allowed only
   for web/mcp) not allowed.
2. **LG-NE-02 floor (unconditional):** metadata endpoint
   `169.254.169.254` denied; private IP `10.0.0.5` denied; **the floor wins
   even when a metadata host is (mis)listed on the allowlist** — code is the
   authority, no allowlist entry overrides it.
3. **LG-NE-06 air-gap:** `mode: deny_all` denies even an allowlisted host.
4. **New-domain routing:** `new_domain_disposition: hitl_approve` routes an
   unlisted host to an approver instead of a hard deny (tunable posture).
5. **Capability preservation:** low-side posture → `check_egress` allows all
   (shipped blocklist path unchanged; complete no-op).
6. **Enclave artifacts:** the compose override mounts the repository-relative
   Squid config; the ACL mirrors the allowlist, permits only TLS `CONNECT`, and
   denies private/link-local destinations after DNS resolution.
